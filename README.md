# GPS Speedometer: ESP32 CYD + NEO-7M

A touchscreen GPS speedometer for the **ESP32-2432S028R** ("Cheap Yellow Display", 320×240 ILI9341 + XPT2046 touch) with a **u-blox NEO-7M** GPS module. The UI is built with LVGL 8.3 and SquareLine Studio.

What it shows:
- Animated needle and arc gauge, plus a digital speed readout
- Odometer, saved to flash and kept across power cycles
- Moving-time stopwatch (counts only while you're moving)
- Compass heading, satellite count, and a local clock from GPS time
- Settings, opened by **long-pressing the gauge**:
  - Scale: max speed 12, 30, 60, 120, 180 or 240
  - Unit: km/h, mph or knots
  - Brightness
  - Clear mileage

## Project layout

| File | Purpose |
|---|---|
| `SpeedometerGPS.ino` | `setup()` / `loop()` only |
| `config.h` | **All settings you can tune:** pins, time zone, speed thresholds, UI timing |
| `gps.h/.cpp` | UART + TinyGPSPlus, speed filtering, moving/stopped detection |
| `app_state.h/.cpp` | Units, scales, brightness and odometer, saved in NVS (flash) |
| `display.h/.cpp` | Connects LovyanGFX to LVGL (display flush + touch) |
| `dashboard.h/.cpp` | Gauge screen: needle, arc, labels |
| `settings_ui.h/.cpp` | Settings and Max-speed screens |
| `LGFX_CYD.hpp` | Panel, touch and backlight setup for the CYD |
| `lv_conf.h` | LVGL configuration (see install notes) |
| `ui.c`, `ui.h` | Generated by SquareLine Studio |

## Wiring

Connect the GPS to the CYD's **CN1** connector (the 4-pin JST, marked GND / IO22 / IO27 / 3V3):

| NEO-7M | CYD |
|---|---|
| VCC | 3V3 |
| GND | GND |
| TX | IO22 |
| RX | IO27 |

Put the GPS antenna where it can see open sky, and keep it a few cm away from the ESP32 and the display backlight. A bad antenna position is the most common reason for an unstable fix.

## Build

### Arduino IDE

1. Install the ESP32 board package and select **ESP32 Dev Module**.
2. Set Tools → Partition Scheme → **Huge APP (3MB No OTA)**. The images and fonts are large.
3. Install these libraries:
   - **lvgl**: exactly **8.3.11** (SquareLine generated the UI for this version; v9 will not compile). If the IDE offers to update lvgl, **decline**: an update to v9 breaks the build.
   - **LovyanGFX**: a recent 1.1.x or newer
   - **TinyGPSPlus** by Mikal Hart
4. Copy `lv_conf.h` to your Arduino `libraries/` folder, **next to** the `lvgl` folder (not inside it):
   ```
   Arduino/libraries/
   ├── lv_conf.h
   └── lvgl/
   ```
5. Open `SpeedometerGPS.ino` and upload.

### PlatformIO

Use `board = esp32dev` and add `-D LV_CONF_INCLUDE_SIMPLE -I .` (or the path to `lv_conf.h`) to `build_flags`.

## Configuration (`config.h`)

| Setting | Default | Meaning |
|---|---|---|
| `TZ_OFFSET_MIN` | 360 | Offset from UTC in minutes (UTC+6) |
| `MOVE_ON_KMH` / `MOVE_OFF_KMH` | 3.0 / 1.5 | Speeds at which you start / stop counting as moving (hysteresis) |
| `GPS_STALE_MS` | 3000 | How long the last speed reading is kept if GPS updates stop |
| `SPEED_SMOOTHING` | 0.3 | Higher reacts faster, lower is steadier |
| `GPS_DEBUG` | 0 | Set to 1 to print GPS status to Serial every second |

## Troubleshooting

### Speed jumps between 0 and a value

Set `GPS_DEBUG 1`, open the Serial Monitor at 115200 baud and watch the output:

| What you see | Cause |
|---|---|
| `age` keeps climbing past 1000–3000 | GPS fix is being lost. Check the antenna position (sats < 5 or hdop > 3 is weak) and the power to the GPS. |
| `bad` keeps increasing | Serial data is corrupted. Check the wiring and the ground connection. |
| `raw` bounces while `age` stays under 1000 | Normal GPS noise at low speed. The hysteresis already handles this; raise `MOVE_ON_KMH` if it still flickers. |

### Other problems

- **Black screen after flashing:** brightness is now limited to at least 5% when it's loaded, so this should no longer happen.
- **Colors wrong or mirrored:** change `invert` / `rgb_order` in `LGFX_CYD.hpp`. Some CYD batches need different values.
- **Touch in the wrong place:** adjust `offset_rotation` and the `x_min`/`x_max`/`y_min`/`y_max` calibration in `LGFX_CYD.hpp`.

## Changes from the original single-file sketch

- **Speed fix:** speed is now smoothed, uses hysteresis for moving/stopped, and keeps the last reading for 3 s if GPS updates stop. This removes the 0 ↔ speed pulsing.
- The code is split into separate modules, and every tunable is in `config.h`.
- The odometer is also saved whenever you come to a stop, so you lose less distance on power-off.
- Brightness can no longer load as 0 and leave the screen black.
- Heading is only updated from a recent course reading.
- `LV_BUILD_EXAMPLES` is off, which saves flash.
- NVS keys are unchanged, so existing devices keep their mileage and settings.
